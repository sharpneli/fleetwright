## Current lean: Fleetwright: Naval Battles
Existing uses of "Fleetwright"/"FleetWright" (Google, 2026-10-08):
- fleetwright.com: aviation maintenance/compliance shared service (Fleetwright (India) Pvt Ltd, <1 yr old)
- fleetwright.app: fleet vehicle repair-tracking SaaS by FMR Digital LLC
- fleetwright.co.uk: UK automotive consultant
- GitHub/MCP open-source projects using the name (fleet telemetry, agents)
- **Closest:** "Fleetwright Web Designer" by SIGSTACKFAULT (GitLab, 2023): ship editor + virtual tabletop for a hobby wargame a friend invented. Same category, but tiny and unpublished; no Steam/itch/BGG listing found.

Assessment: all commercial users are in fleet/aviation maintenance software, a different market from games, so low confusion risk. Practical costs: .com and .app taken; search results dominated by those firms for now. Mitigations: always use the full title / subtitle, spell "Fleetwright" (not "FleetWright"), use a domain like fleetwright.games or fleetwrightgame.com, optionally ping SIGSTACKFAULT as a courtesy.
